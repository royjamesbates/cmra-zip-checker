Is This Address a Mailbox or Virtual Office?

Enter a ZIP code to see which addresses in that area are registered commercial mail receiving agencies (CMRAs), UPS Stores, mailbox shops, or virtual offices. No server names — just the locations, so you can verify whether a process server's listed office is real.

Data is compiled from public records: USPS CMRA registry, known UPS Store and mailbox shop locations, and virtual office providers. This tool does not name individual process servers. It flags the address type so attorneys and serve managers can ask the right question: is there a staffed counter at this exact suite during business hours?
